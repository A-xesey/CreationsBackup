**CreationsBackup** is the mod that adds backup possibility in editors and adventure editor.

Backups are saving in AppData\Roaming\Spore\Backups path by their type (Adventures, Creatures...), creation name and numeration
**Be careful!** If creation hasn't the name, mod will create a folder with hash and send backups here. Just rename the folder to creation's name when u named it

In the same directory there are also a Preferences\BackupSettings.prop file that requires to backup control:
BackupByStepADV and BackupByStepEDT determines how many steps to take before making a backup
BackupEnable is the mod's switcher
EditorAllowXMLFileDrop in-game property using for importing in the editor valid creations


**Also mod has:**
* The "backupcreations" cheat to setting the BackupSettings.prop from console
* Import in the game the creation formats (.crt, .vcl, .ufo, e
